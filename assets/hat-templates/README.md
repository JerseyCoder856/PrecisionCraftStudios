# Hat template image filenames

The snapback editor loads real hat photos from this folder by color using this filename pattern:

- `redhat.png`
- `bluehat.png`
- `blackhat.png`
- `greenhat.png`
- `yellowhat.png`
- `pinkhat.png`
- `whitehat.png`

Each PNG is used as the background/template layer for customers to place artwork on top of. If a PNG is missing, the editor falls back to the matching SVG placeholder for that color.
